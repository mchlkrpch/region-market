# Ядро визуализатора

**Crypto Workspace** — интерактивный визуализатор региональных криптовалютных рынков и реакции цен на новости. Он позволяет выбирать монеты и регионы, сравнивать графики с шагом от 15 минут и исследовать доходность, волатильность и объём до и после событий в настраиваемых временных окнах.

![Визуализатор Crypto Workspace: выбор монет, графики и статистика реакции на новости](docs/images/visualizer.png)

Код интерактивного Crypto Workspace находится в [`vizualizer/explorer/`](vizualizer/explorer/).

- Интерфейс: сетка графиков, выбор регионов и групп монет, масштабирование и перемещение, 15-минутные свечи.
- Новости: отметки событий и исследование реакции, бинарные исходы, связанные цепочки, окна t1/t2/t3, группировка и копирование отчёта.
- Сервер: Python 3 и стандартная библиотека. Клиент: JavaScript, HTML, CSS и Canvas, без сборки и внешних библиотек.

**Датасеты котировок и новостей не публикуются.** Также отсутствуют исходные ответы API, кэши цен и прежняя статическая сборка со встроенными котировками. В репозитории только код, тесты и документация.

## Какие данные использовались

Период исследования — **июль 2025 — июнь 2026**, спотовые OHLCV-свечи с шагом **15 минут**. В каталоге визуализатора — **116 уникальных монет, 498 пар и 7 региональных рынков**; состав монет различается между рынками.

- **Рынки:** США (Coinbase, USD), еврозона (Bitvavo, EUR), Индонезия (Indodax, IDR), Таиланд (Bitkub, THB), Южная Корея (Upbit и DigitalX / бывший Korbit, KRW), Гонконг (HashKey и OSL, HKD/USD), ОАЭ (OKX, AED). Материковый Китай представлен в новостях; для сопоставления с криптовалютными ценами используются гонконгские котировки.
- **Типы монет — 14 групп:** базовые сети и платежи; идентификация и приложения; DEX; DePIN и сетевые сервисы; оракулы, данные и межсетевые связи; L2 и масштабирование; AI и вычисления; деривативы; игры; мемкоины; кредитование и активы; стейкинг и стейблкоин-протоколы; RWA; токены публичных фигур.
- **Новости:** 4 634 записи по США, еврозоне, Индонезии, Таиланду, Южной Корее, Китаю, Гонконгу и ОАЭ, объединённые в 16 типов. Это ставки и денежная политика, инфляция, занятость, ВВП и производство, PMI, торговля, кредитная статистика, жильё, аукционы, регулирование, криптотехнологии, политика, компании, выступления, регулярные обновления и прочие сообщения. Источники включают центробанки и статистические службы, WAM, ANTARA и S&P Global PMI.

В разметке выделены бинарные исходы (например, снижение / повышение / сохранение ставки, одобрение заявки) и связанные цепочки «анонс → результат». Для внутридневного анализа используются события с известным временем; записи только с датой рассматриваются отдельно. Наблюдаемые изменения описывают совпадение во времени и сами по себе не доказывают причинность.

**Это описание состава исследования. Сами котировки, новости и исходные ответы API в репозитории отсутствуют.**

## Запуск с локальными данными

Сервер ожидает соседний каталог `src/regional_crypto_15m/` из исходного исследовательского проекта. Можно подключить существующий каталог символьной ссылкой; файлы данных при этом остаются вне репозитория:

```bash
# Из корня клонированного region-market:
ln -s /absolute/path/to/regional_crypto_15m src/regional_crypto_15m
cd src
python3 vizualizer/explorer/server.py
```

Открыть <http://127.0.0.1:8765>. Другой порт: `--port 8766`.

Внешние данные нужны для работы сервера: `news_ab_2025_07_2026_06/price_series.json`, определения наборов `semester_universe.json` и `us_kr_universe.json`, исторические CSV по путям из `price_series.json`, новостные календари и семантическая разметка. Их содержимое в эту публикацию не включено. Подробная документация интерфейса и методов расчёта: [`README.txt`](vizualizer/explorer/README.txt).

## Проверки без датасетов

Для клиентских проверок нужен Node.js, для серверных — Python 3:

```bash
cd src
node vizualizer/explorer/test_date_input.cjs
node vizualizer/explorer/test_study.cjs
node vizualizer/explorer/test_selection.cjs
node vizualizer/explorer/test_plot.cjs
python3 -m unittest discover -s vizualizer/explorer -p 'test_event_study.py'
```

Проверки сохранённых исследовательских данных пропускаются, если внешний каталог отсутствует. Остальные проверки работают автономно.
